# 管道產物靠來源標記辨識，不靠所在位置

管道要判斷一個檔案是不是自己的產物時，看的是檔案裡的來源標記，而不是它落在哪個資料夾。直覺的做法是「`Claude Code/` 底下的都是封存、`GitHub Stars/` 底下的都是筆記」，直接掃資料夾就好；我們刻意不這樣做，因為使用者本來就會在這些資料夾裡放自己的東西（撰寫本 ADR 時 `Claude Code/` 底下就已經躺著一篇使用者手寫的筆記），而靠位置判斷會讓任何未來的清理、對帳、重建索引功能把它們一併當成管道產物處理掉。

## Consequences

沒有來源標記的檔案，等於宣告「不屬於任何管道」，管道必須跳過它。這條規則的代價是**標記必須先存在**：撰寫本 ADR 時，封存已經有來源標記，但既有的 76 篇 star 筆記都沒有——在補上之前，它們會被新規則判定為使用者檔案而永遠跳過。導入這條規則時必須一併處理既有筆記的回填。
